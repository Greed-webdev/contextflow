# Так больше не делать

Живой список дыр, которые уже ловили. Новую ошибку из ревью — сюда в тот же заход.
Судьи: `js/lessons.js`. Навигация: `js/app.js`. Превью ≠ прод.

## Навигация

- Экран без своего `open()`/`render()` в `go()` открывается пустым. Атлас — `Atlas.open()`, и гасить старый `raf` перед новым.
- Не говорить «промпт устарел», если владелец кинул файл ещё раз: сверить код, дожать, не отмахиваться.

## Судья: выбор и отрицание

- Слово = выбор или утверждение → `chose()`, не голый `has()`. «Do not block the SIM» не должно идти в ветку «блокируем».
- Отрицание проверять **до** позитивной ветки.
- Не ломать уже верные ветки: `I have no tag` → notag, `I forgot my passport` → miss, `I have nothing with me` → none, `It is not the noise, it is a leak` → leak.
- Вопрос (`what`/`when`/`how`), вежливость (`thanks`/`please`), намерение без выбора — `has()` можно оставить.

## Судья: мусор вместо ответа

- Никогда `if (w.length >= N) return {br:'ok'}`. Два любых слова — не ответ.
- Имя: `NOT_NAME` + `NAME_OK`/`looksLikeName`. Мат, banana, asdfgh, `<script>` — переспрос.
- Имя + дата: нужны **оба** признака. Одна Анна без даты — переспрос. Дата без имени — переспрос.
- Адрес: не принимать `lorem ipsum` только из‑за длины.

## Русский и «как будто английский»

- `norm()` выкидывает кириллицу. Русская фраза не должна проходить запасной веткой «ну хоть что‑то написал».
- Если после `norm` пусто и в сырье есть `а-я` — переспрос «попробуй по-английски», не ветка ok.

## Деплой

- Правки тестировщика — в `Greed-webdev/contextflow-preview`, не в прод `contextflow`.
- После правки судей — прогнать фразы из приёмки ревью, не только `best`.
