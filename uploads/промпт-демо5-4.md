## 1. Узел `meet` принимает вообще всё — критический

**Где:** узел `meet` сцены S1, функция `judge`.

Сейчас там:

```js
judge(w){ if(!has(w,'no','not')&&has(w,'yes','yeah','sure','meeting','meet','appointment')) return {br:'meet'};
    if(has(w,'home','leave','going','go','bye','later','nothing')) return {br:'home'};
    if(has(w,'help','lost','wait','friend','someone','person','look','find','another','wrong','just')) return {br:'other'};
    return {br:'ask'}; },
```

Последняя строка — `return {br:'ask'}` — делает узел свалкой. Это единственный узел во всём демо без `huh`, поэтому любой непонятый ввод считается осмысленным.

Что происходит:

```
— Are you here for the meeting?
— no
— What can I do for you?
```

Прямое «нет» на прямой вопрос не распознаётся как отказ: слово `no` не попадает ни в одно условие и проваливается в дефолт. Также проходят `banana`, `!!!`, `777`, `a`, `the the the` — всё уходит в ветку `ask`.

**Замени функцию целиком на эту:**

```js
judge(w){ const neg=has(w,'no','not','nope','never');
    /* «no» на прямой вопрос — это отказ, а не «чем помочь» */
    if(neg&&has(w,'meeting','meet','appointment')) return {br:'home'};
    if(!neg&&has(w,'yes','yeah','sure','meeting','meet','appointment','course','right','correct','exactly')) return {br:'meet'};
    if(has(w,'home','leave','leaving','going','go','bye','later','nothing')) return {br:'home'};
    if(neg) return {br:'home'};
    if(has(w,'help','lost','wait','waiting','friend','someone','person','look','find','another','wrong','just')) return {br:'other'};
    if(has(w,'what','why','sorry','pardon','repeat','again','know','understand')) return {br:'ask'};
    return {huh:1}; },
```

Ветки `tr` не меняй, они те же.

## 2. Ловушка на отрицании в узле `miss`

**Где:** узел `miss` сцены S3, функция `judge`.

Сейчас там:

```js
judge(w){ if(has(w,'no','not','never')) return {br:'no'};
    if(has(w,'yes','very','miss','sure','course','sometimes','little','bit','lot','always','every','day','terribly','really')) return {br:'yes'}; return {huh:1}; },
```

Отрицание проверяется по всей фразе и стоит первым. Поэтому «no, I really miss them» уходит в отказ, хотя это согласие — `no` здесь вежливая частица, а не отрицание глагола.

**Замени функцию целиком на эту:**

```js
judge(w){
    /* «no, I really miss them» = согласие: отрицание относится к вежливому «no»,
       а не к глаголу. Отказ — только когда not/never стоит ВПЛОТНУЮ к miss. */
    const hardNo=w.some((x,i)=>(x==='not'||x==='never'||x==='do')&&
      (w[i+1]==='miss'||w[i+2]==='miss'||(w[i]==='not'&&w[i+1]==='really'&&!has(w,'miss'))));
    if(hardNo) return {br:'no'};
    if(has(w,'yes','very','miss','sure','course','sometimes','little','bit','lot','always','every','day','terribly','really')) return {br:'yes'};
    if(has(w,'no','not','never')) return {br:'no'};
    return {huh:1}; },
```
