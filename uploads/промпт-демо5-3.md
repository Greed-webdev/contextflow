## 1. Узел `num` принимает неверный ответ как верный — БЛОКИРУЮЩИЙ

**Где:** строки 186–188, узел `num` сцены S2 (уровень 6).

В этот узел ведут две ветки из `addr` с **противоположными вопросами**:

- игрок назвал только улицу → ветка `ok` → «Thank you. And the house number, please?» — ждём номер дома
- игрок назвал только номер → ветка `which` → «Sorry, which street is it?» — ждём улицу

А судья один на оба случая:

```js
judge(w,mem){ if(has(w,'park')) return {br:'ok'};
  if((mem._digits||[]).length||numOf(w)!==null) return {br:'ok'}; return {huh:1}; },
```

Он принимает и улицу, и номер, не различая, что именно спросили. Проверено стендом:

| Что спросили | Что ответил игрок | Результат |
|---|---|---|
| Which street is it? | `999` | принято как верное |
| And the house number? | `Park Street` | принято как верное |

Собеседник задаёт конкретный вопрос и не замечает, что ему ответили не на него. Для тренажёра это прямой вред — ошибка засчитывается как успех.

**Что сделать.**

Раздели узел `num` на два: один ждёт номер дома, другой ждёт название улицы. В `addr` (строки 180–184) ветка `ok` должна вести в узел с проверкой номера, ветка `which` — в узел с проверкой улицы.

Узел «ждём номер»: принимать только цифры или числительные (`numOf`, `mem._digits`). Слово `park` без числа — не принимать, переспросить.

Узел «ждём улицу»: принимать только `park` или `street`. Голое число — не принимать, переспросить.

Поле `task` сейчас одно на оба входа — «Уточни адрес: Парк-стрит, 12». Разведи: «Назови номер дома: 12» и «Назови улицу: Парк-стрит».

## 2. Узлы `miss` и `visit` отбивают естественные ответы

**Где:** строки 236–238 (`miss`) и 241–243 (`visit`), сцена S3, уровень 9.

Тот же класс дефекта, что был с «one month» в узле `stay` — починили в одном узле, соседние остались.

### Узел `visit`, строка 242

```js
if(has(w,'summer','came','come','visit','june','july','august')) return {br:'yes'};
if(has(w,'no','not','never','yet','busy')) return {br:'no'};
```

Вопрос собеседника — «Do they visit you here?». Это вопрос типа да/нет. Но:

- голое `yes` → не понял
- `every year` → не понял
- `last month` → не понял

Отбивается самый естественный ответ на заданный вопрос.

**Что сделать:** добавить в ветку `yes` слова `yes`, `yeah`, `sure`, `often`, `every`, `year`, `sometimes`, `spring`, `autumn`, `winter`, `month`, `week`, `last`, `time`, `twice`.

### Узел `miss`, строка 237

```js
if(has(w,'no','not','never')) return {br:'no'};
if(has(w,'yes','very','miss','sure')) return {br:'yes'};
```

Вопрос — «Do you miss them?». Не принимаются:

- `of course` → не понял
- `sometimes` → не понял
- `a little` → не понял

**Что сделать:** добавить в ветку `yes` слова `course`, `sometimes`, `little`, `bit`, `lot`, `always`, `every`, `day`, `terribly`, `really`.

Порядок проверок не меняй: отрицание должно проверяться первым, иначе «no, not really» уйдёт в `yes` из-за слова `really`.

## 3. Ветка `fix` не срабатывает там, где нужна

**Где:** строки 44–46 и ветка `fix` в `tr` узла `n0`, сцена S1, уровень 3.

Ветка `fix` существует для случая, когда игрок назвал имя криво, и показывает подсказку «My name is Anna». Но достижима она только ломаным порядком слов — `name Anna`, `Anna name`, `name is Anna`.

Живая разговорная форма мимо:

- `call me Anna` → имя становится **Call**, ветка `greet`, подсказка не показывается

То есть механизм исправления не срабатывает там, где он как раз нужен.

**Что сделать:** добавить `call` в `NAME_STOP` (строка 19), чтобы имя бралось верно. И направить конструкцию `call me X` в ветку `fix` — игрок понят, но ему показывается более уместная форма «My name is Anna».
