## BUG-03 · Петля без выхода + `best` в КОНЕЦ

**1. Путь:** `демо-6.html`, сцена S1 «Назвать количество · ур. 14», узел `change`
**2. SHA:** `11dd4ab973f7e13568d96c956155207744693493`

**3. Кусок `judge` из лога:**

```js
change:{ task:'Поблагодари и проверь сдачу...', best:'Thank you. That is right.',
judge(w){ const pos=['right','ok','okay','fine','correct','good'];
  const negHit = pos.some(x=>{ const i=w.indexOf(x); return i>-1 && negatedAt(w,i); });
  if(has(w,'wrong','short','mistake','incorrect')||negHit) return {br:'recheck'};
  if(w[0]==='no'||w[0]==='not') return {br:'recheck'};
  if(has(w,'thanks','thank')||pos.some(x=>w.includes(x))) return {br:'ok'};
  return {huh:1}; },
tr:{ ok:     {them:'You are welcome. Have a nice day!', next:null},
     recheck:{them:'Sorry. Let me count again. Here you are.', next:'change'} } },
```

**Два дефекта в одном узле:**

- `recheck` → `change` — самовозврат, других веток с `next` нет. Игрок, повторяющий «it is wrong», крутится бесконечно. Уступки на третьем круге нет, хотя в узлах `count`, `twelve`, `pick` этого же файла она реализована.
- `best` = `Thank you. That is right.` → ветка `ok` → `next:null`. Кнопка «Не знаю» закрывает сцену вместо продолжения.

**Фикс:** счётчик в `mem`, на третьем `recheck` — уступка с выходом. Проверить, должен ли `ok` быть финальным.

## BUG-04 · `best` ведёт в КОНЕЦ при наличии продолжений

**1. Путь:** `демо-5.html`, сцена S1, узел `wait`
**2. SHA:** `cd92b296634c5dfb0cef12f82298268e285b736b`

**3. Кусок `judge` из лога:**

```js
wait:{ task:'Поблагодари.', best:'Thank you very much.',
  judge(w){
    if(has(w,'problem','worries','worry')) return {br:'ok'};
    if(isNegatedIntent(w,['wait'])||has(w,'no','not','never')) return {br:'refuse'};
    if(has(w,'thanks','thank','ok','okay','sure','fine','great','good','alright','right','cheers','nothing','bye','goodbye')) return {br:'ok'};
    return {huh:1}; },
  tr:{ ok:    {them:'You are welcome.', next:null},
       refuse:{them:'No problem. Please take a seat...', next:'bye'} } },
```

`best` → `ok` → `next:null`, при этом `refuse` → `bye`. Эталонный ответ обрывает сцену, отказ — продолжает. Логика перевёрнута.

**Фикс:** `ok` должен вести в `bye`, как и `refuse`.

## BUG-05 · Сложное отрицание · 6 пробоев из 8

Автопроверка тестирует форму `no X`. Конструкции ниже её обходят.

**SHA:** демо-6 `11dd4ab…`, демо-7 `…`, демо-8 `691b3cc…`, демо-9 `…`, демо-10 `…`

| Файл | Узел | Ввод | Ветка | Реплика собеседника |
|---|---|---|---|---|
| демо-6 | `pay` | `I cannot pay in cash.` | `cash` | «Here is your change.» |
| демо-6 | `pick` | `Black is not what I want.` | `black` | «Black is a good choice.» |
| демо-7 | `since` | `It is not since yesterday.` | `yest` | «Take this medicine and rest today.» |
| демо-8 | `ready` | `I am not ready to order.` | `yes` | «Great! What would you like?» |
| демо-9 | `call` | `The light is not the problem.` | `nlight` | «The light? Since when?» |
| демо-10 | `sr` | `A return is not what I need.` | `ret` | «Return. That is six euros.» |

Отбито верно: демо-5 `floor` (`Room 204, not second floor` → `huh`), демо-8 `try` (`It is not the right size` → `bad`).

**Причина:** `negatedAt(w,i)` ищет отрицание **слева** от цели в коротком окне. Не покрывает:

- `X is not …` — отрицание справа от цели
- `cannot` / `can't` / `won't` перед глаголом действия
- `not the right X`, `not what I want` — отрицание через связку

**Фикс:** доработать общий хелпер, прогнать на всех шести файлах. Правка в одном месте.
