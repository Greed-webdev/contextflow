# QA-стенд ContextFlow

- `engine.js` — вырезает ядро (SCENES+хелперы) из `демо-5.html`.
- `harness.js` — прогон диалога фразами (копия D.go).
- `adversarial.js` — враждебный прогон: каждому узлу-судье скармливает ~80 живых
  фраз новичка (мусорные имена, вежливые no/not, голые yes/no, обрывки, русские имена).
  Не ломает — показывает слепые зоны. Запуск: `node qa/adversarial.js`.

## Правило (заведено 2026-09-06 по решению владельца)
Перед словом «готово» каждый узел/диалог прогоняется ДВАЖДЫ:
1. эталонный проход (фразы урока) — обязан доходить до конца;
2. враждебный прогон — живые фразы, чтобы видеть, где сценарий глух.

Продакшен-движок (judge в js/app.js) на враждебном наборе принимает ~8-10%
живых фраз — это системная слабость, чинить перед/во время раскатки на 60 диалогов.
