# Как выложить ContextFlow в Telegram

Всё бесплатно. Займёт минут 15 в первый раз.

Заливать нужно **папку `deploy`** — там только то, что нужно приложению.
Ничего лишнего: ни правил, ни бэкапов, ни старых версий.

---

## Часть 1. Положить приложение в интернет

Telegram не хранит файлы у себя. Он открывает страницу по ссылке,
поэтому страница должна где-то лежать. И обязательно по **https** —
без него Telegram не запустит приложение, а браузер не даст микрофон.

### Vercel — самый простой путь

1. Заходишь на **vercel.com**, регистрируешься (можно через GitHub или почту).
2. Нажимаешь **Add New → Project**.
3. Выбираешь **Deploy without Git** (или вкладку с загрузкой папки).
4. Перетаскиваешь туда папку **`deploy`** целиком.
5. Ждёшь минуту. Получаешь ссылку вида:
   ```
   https://contextflow-xxxx.vercel.app
   ```
6. Открой её в браузере — приложение должно запуститься.

Эту ссылку сохрани, она нужна дальше.

### Если Vercel не понравился

**Netlify** — то же самое: netlify.com → Add new site → Deploy manually →
перетащить папку `deploy`.

Файлы настроек уже лежат внутри: `vercel.json` для Vercel,
`_headers` для Netlify. Они разрешают Telegram показывать приложение
и открывают доступ к микрофону. Ничего настраивать руками не надо.

---

## Часть 2. Привязать к боту

1. Открой в Telegram **@BotFather**.
2. Отправь `/newbot`.
3. Придумай имя — например `ContextFlow`.
4. Придумай логин — обязан заканчиваться на `bot`, например `contextflow_app_bot`.
5. Получишь токен — длинную строку. Сохрани её, пригодится позже.

Теперь привязываем приложение:

6. Отправь `/newapp`.
7. Выбери своего бота из списка.
8. Название приложения — `ContextFlow`.
9. Описание — например «Изучение языков через восхождение на гору».
10. Картинку — любую 640×360.
11. **Ссылку с Vercel** — ту самую, из первой части.
12. Короткое имя (для прямой ссылки) — например `app`.

Готово. Открывай своего бота в Telegram — там появится кнопка запуска.

---

## Часть 3. Проверить микрофон

Ради этого всё и делалось.

1. Открой бота **на телефоне**, запусти приложение.
2. Зайди в любой урок со словами.
3. Нажми **«Сказать»**.
4. Должно появиться системное окно **«Разрешить доступ к микрофону?»** —
   нажми «Разрешить».
5. Надпись сменится на «Говори» — произнеси слово вслух.
6. Увидишь распознанный текст и процент совпадения.

**Если окно не появилось**, приложение само покажет инструкцию
под твой телефон — просто следуй шагам на экране.

Кратко:
- **iPhone:** Настройки → Telegram → включить «Микрофон»
- **Android:** зажать иконку Telegram → О приложении → Разрешения →
  Микрофон → Разрешить

После этого **закрой и снова открой** мини-приложение — иначе не подхватится.

## Как обновлять после доработок

Приложение **само не обновится**. На хостинге лежит копия, снятая в момент заливки.

Когда мы что-то доработаем:

1. Скажи мне «собери папку для заливки» — обновлю `deploy`.
2. Скачай её.
3. На Vercel: проект → **Deployments** → перетащить папку заново.
4. Ссылка останется прежней, бота перенастраивать не нужно.

Минута работы. Если правки станут частыми — можно настроить
автообновление через GitHub, скажи, и разберёмся.

**Важно про кэш:** настройки уже прописаны так, что код и стили
подтягиваются свежими сразу, а тяжёлые картинки кэшируются надолго.
Так что после перезаливки пользователи увидят изменения без чистки кэша.

---

## Если что-то пошло не так

**Приложение не открывается в Telegram** — проверь, что ссылка начинается
с `https://` и открывается в обычном браузере.

**Микрофон не просит доступ** — открыто по `http` вместо `https`.
Так работать не будет, это защита браузера.

**Изменения не видны после перезаливки** — закрой мини-приложение
полностью и открой заново. В Telegram: свайпнуть вниз, потом снова запустить.
