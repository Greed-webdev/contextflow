## Что осталось сделать тебе (5 минут)

### Шаг 1. Создать бота

Открой в Telegram **@BotFather** и отправь:

```
/newbot
```

Дальше он спросит:
- **Имя бота** — любое, например `ContextFlow`
- **Логин бота** — обязан заканчиваться на `bot`,
  например `contextflow_app_bot` (если занят — придумай другой)

В ответ придёт токен бота. Сохрани его, пригодится в будущем.

### Шаг 2. Привязать приложение

Там же отправь:

```
/newapp
```

Дальше по порядку:
1. Выбери своего бота из списка
2. **Название** — `ContextFlow`
3. **Описание** — например «Изучение языков через восхождение на гору»
4. **Картинка** — любая 640×360
5. **GIF** — можно пропустить, отправь `/empty`
6. **Ссылка** — вставь:
   ```
   https://greed-webdev.github.io/contextflow/
   ```
7. **Короткое имя** — например `app`

Готово. Открывай своего бота — там будет кнопка запуска.

### Шаг 3. Проверить микрофон

1. Запусти приложение **на телефоне**
2. Зайди в урок со словами
3. Нажми **«Сказать»**
4. Должно появиться окно **«Разрешить доступ к микрофону?»** → разреши
5. Скажи слово вслух — увидишь распознанный текст и процент

Если окно не появилось, приложение само покажет инструкцию под твой телефон.

## Как обновлять после доработок

Теперь это одна команда. Только нужен токен GitHub —
он не сохраняется между сессиями, это защита платформы.

```
GH_TOKEN=ghp_твой_токен ./обновить-сайт.sh
```

Сайт обновится за 1–2 минуты. **Ссылка не меняется**, бота
перенастраивать не надо.

Обычно я сделаю это сам — просто скажи «обнови сайт» и дай токен.

**Важно:** после обновления закрой мини-приложение в Telegram
полностью (свайп вниз) и открой заново, иначе покажется старая версия.

### Если токен истёк

Сделай новый: https://github.com/settings/tokens/new
Срок — 7 дней, галочка только **repo**.

## Безопасность

Текущий токен использован только для подключения и **нигде не сохранён** —
ни в файлах, ни в истории. Я проверил.
